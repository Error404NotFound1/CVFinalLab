\chapter{实验综述}
\label{chap:overview}

本实验为 CS231n Assignment 3，主要涉及计算机视觉领域的前沿技术，包括自监督学习、Transformer 架构、大规模预训练模型以及生成模型。

本报告将依次介绍以下四个部分的实验内容：
\begin{enumerate}
    \item \textbf{自监督学习 (Self-Supervised Learning)}：实现 SimCLR 算法，通过对比学习在无标注数据上学习图像表示。
    \item \textbf{Transformer 图像字幕 (Transformer Image Captioning)}：利用 Transformer 架构实现图像到文本的自动描述生成。
    \item \textbf{大规模预训练模型 (Large-scale Pre-trained Models)}：探索 CLIP 和 DINO 等模型在特征提取和下游任务中的应用。
    \item \textbf{生成模型 (Generative Models)}：实现去噪扩散概率模型 (DDPM)，探索图像生成的原理。
\end{enumerate}
